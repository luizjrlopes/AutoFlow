# Restrições Legais — AutoFlow IA

## Projeto educacional e de portfólio

Não coleta dados reais de usuários. Os dados de exemplo (Maria Silva, Joao Souza) são fictícios, gerados automaticamente, e existem apenas localmente.

## Se plugar um LLM real

- Não enviar dados pessoais reais para APIs externas (OpenAI, Anthropic, etc.)
- Verificar os termos de uso da API quanto a armazenamento e uso dos prompts enviados
- Manter a chave de API fora do código (variável de ambiente) — nunca commitar no git

## Simulação de canais

O campo `canal` (whatsapp/telegram) é uma simulação educacional. O projeto não é integrado a nenhuma API real de WhatsApp Business ou Telegram Bot.
